## 🌌 Introduction

Welcome to **g-coder v1.0.0**, the ultimate autonomous Artificial Intelligence engineering suite built exclusively for the terminal. `g-coder` is not just another wrapper; it is a sentient, self-evolving, polyglot orchestrator capable of replacing entire architectural and QA teams.

Built with extreme performance and offline-first hybrid heuristics, `g-coder` is designed for elite developers who demand speed, security, and true autonomous orchestration.

## ⚡ Key Features

*   **🌍 Polyglot Fluency:** Supports over 500+ programming languages and system scripts natively.
*   **🧠 Hybrid Execution Engine:** Automatically routes metadata and system-level intents to high-speed local binary parsers (Zero API tokens used, Offline-First capable).
*   **🧬 Self-Evolving Capabilities:** If a command is requested that `g-coder` doesn't know, it dynamically writes its own code, installs its own dependencies into a sandbox, and executes the new capability on the fly.
*   **⏱️ Quantum Time-Travel Debugger:** Hooks into `git bisect` to autonomously hunt historical regression bugs across your timeline, generating mathematical patches to fix them.
*   **👻 Live Ghost Coder Server:** An active IPC WebSocket bridge that streams AI-generated code token-by-token directly into your IDE.
*   **🛡️ Stateful 429 Resilience:** Multi-provider API load-balancing with exponential backoff and session persistence.

## 📦 Installation

```bash
# Install globally via npm
npm install -g g-coder

# Verify installation
g-coder --version
```

## 🚀 Quick Start & Core Commands

Once installed, simply invoke `g-coder` followed by your command:

| Command | Description |
|---|---|
| `g-coder config` | Initialize API keys and preferences interactively. |
| `g-coder hybrid <prompt>` | The Omni-Router. Give it any natural language task. |
| `g-coder evolve <task>` | Synthesize a missing capability dynamically. |
| `g-coder inspect <file>` | Extract ultra-fast binary metadata and security telemetry. |
| `g-coder quantum <testCmd> <goodCommit>` | Time-Travel regression bug hunter. |
| `g-coder ghost-server` | Start the local IPC WebSocket for live IDE typing. |
| `g-coder update` | Safely update the global g-coder installation. |
